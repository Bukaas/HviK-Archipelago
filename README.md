# HviK Archipelago

Starterpakete, YAML-Vorlagen und Werkzeuge für die Archipelago-Runden der HviK Community.

Anleitungen für Spieler und Hosts: **https://hvik.org/events/archipelago** (Discord-Login)

## Inhalt

| Ordner | Was |
|---|---|
| `yaml/` | YAML-Vorlagen pro Spiel (`{{NAME}}` wird auf der Website durch den Spielernamen ersetzt) |
| `packages/<spiel>/` | Inhalt der Starterpakete – fertige Downloads gibt es unter **Releases** |

## Downloads

Die Starterpakete liegen als ZIP unter [Releases](../../releases) – nicht im Repo selbst, damit es klein bleibt.
