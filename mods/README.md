# HviK Link (Minecraft)

Mod fuer gekoppelte Einzelspieler-Welten (geteilte Herzen/Hunger, Death Link, gemeinsamer Start) ueber hvik.org/games/minecraft.

- `hviklink-forge-1.20.1/` - Cube Warper (Forge 47, Java 17). Bauen: `gradlew build` (JAVA_HOME = JDK 17).
- `einrichten.ps1` / `entfernen.ps1` - liegen im persoenlichen Paket (kopiert das CurseForge-Profil).
